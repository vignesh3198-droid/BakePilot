🔒 Multi-Tenant Data Quarantine Architecture

✓ Isolated Sandbox: Each baker's data is quarantined into /data/users/<userId>/database.json. No baker can ever view another baker's records.
✓ SHA-256 Hashing: Passwords use one-way cryptographic SHA-256 with rotating user tokens. Plaintext passwords are never stored.
✓ 100% Recipe Ownership: Proprietary formulas, client lists, and pricing margins are exclusively owned by each home baker.
✓ EOD 11:50 PM Backup Vaults: Independent automated snapshots archived nightly in user backup folders.
